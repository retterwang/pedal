# PEDAL - 真实物理引擎汽车加速模拟器

一个基于纯前端技术的拟物风格汽车驾驶模拟器。通过 Canvas 渲染高仿真仪表盘，配合物理引擎模拟加速、换挡、刹车、滑行等真实驾驶行为，并按车型参数严格校准 0-100 km/h 加速时间与最高车速。

## 功能特性

- 🚗 **真实车型数据库**：17 个品牌 100+ 款车型（BMW、Mercedes-Benz、Audi、Porsche、Tesla、比亚迪、蔚来、小鹏、理想等），每款包含真实的 0-100 加速时间、最高时速、发动机类型、功率、刹车性能等参数
- 🎛️ **拟真仪表盘**：Canvas 多层渲染，金属拉丝质感边框、大小刻度线、红色危险区、7 段 LED 车速显示、档位指示器；燃油车额外配备带红线区的转速表
- ⚙️ **真实物理引擎**：基于 0-100 加速时间推导加速度，综合考虑扭矩曲线（峰值型/平缓型/线性型）、空气阻力（与速度平方成正比）、滚动阻力、换挡扭矩中断、软限速因子
- 🔧 **变速箱模拟**：燃油车参考 ZF 8HP、Aisin 6AT、Getrag 7DCT 等真实齿比序列；电动车模拟电机瞬时扭矩特性并配备动能回收
- 📊 **数据严格匹配**：0-100 km/h 加速时间与车型参数误差 < 0.02s，最高车速同样匹配

## 使用

直接用浏览器打开 `index.html` 即可，无需构建、无需安装依赖。

也可以在线体验：**[PEDAL 在线 Demo](https://pedal.abetterplace2.live)**
