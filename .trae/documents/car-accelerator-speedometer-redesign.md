# 汽车加速模拟器 - 仪表盘拟真改造计划

## 摘要
将现有的汽车加速模拟器的车速表从简约风格改造为拟真风格，模仿真实汽车仪表盘的指针设计，同时保持整体界面简洁不科幻。

## 现状分析

### 已有功能（无需改动）
- **品牌/车型选择系统**：17个品牌，每品牌8款车型，含0-100加速时间、最高时速、发动机、功率、刹车性能数据
- **物理引擎**：基于0-100加速时间推导加速度，考虑扭矩衰减、空气阻力、滚动阻力
- **油门/刹车控制**：按住加速、松开滑行/刹车，支持鼠标和触摸
- **键盘控制**：W/上方向键油门，S/下方向键刹车，R重置
- **性能数据面板**：当前速度、加速时间、行驶距离、平均加速度、速度曲线图
- **档位/RPM模拟**：6档自动换挡逻辑，RPM条显示

### 需要改进的核心问题
1. **车速表不够拟真**：当前使用CSS div实现指针，刻度线用transform旋转div，整体偏简约/数字风格
2. **缺少真实仪表盘元素**：没有红色危险区标记、没有内圈装饰、指针造型不够真实
3. **刻度盘视觉层次不足**：大小刻度区分不够明显，数字排列不够紧凑

## 改造方案

### 1. 仪表盘重设计（Canvas绘制）

将速度表从CSS div方案改为**Canvas绘制**，实现更精细的拟真效果：

**表盘底面**：
- 深色底面（深灰/黑色渐变），模拟真实仪表盘
- 外圈金属质感边框（银色渐变）
- 内圈细线装饰环

**刻度系统**：
- 大刻度：每20km/h一条，白色粗线，带数字标注
- 小刻度：每10km/h一条，白色细线
- 红色危险区：超过最高时速80%的刻度区域标红
- 刻度弧线：在刻度内侧绘制一条细弧线连接所有刻度

**指针**：
- 造型：底部宽、尖端细的三角形，模拟真实指针
- 颜色：橙红色（#E84C3D），带轻微阴影
- 中心帽：银色金属质感圆形
- 指针运动：使用CSS transition实现平滑过渡（0.08s ease-out）

**数字显示**：
- 中心大数字显示当前速度（保留）
- "km/h"单位标注
- 底部小字显示车型名称

### 2. 整体界面风格调整

**配色方案**：
- 仪表盘区域：深色主题（深灰底+白色刻度+红色指针），与真实汽车一致
- 其他区域：保持现有浅色简洁风格
- 形成深色仪表盘+浅色控制面板的对比

**布局微调**：
- 仪表盘尺寸适当增大，成为视觉焦点
- RPM条和档位指示器移至仪表盘下方，风格统一
- 油门/刹车按钮保持现有设计

### 3. 具体实现细节

#### 文件：`code.html`

**A. 新增Canvas元素替换现有speedometer div**
- 在现有speedometer容器内，用`<canvas>`替换CSS刻度和指针
- Canvas尺寸：400x400（2x DPI支持：800x800实际像素）

**B. 新增绘制函数（在UI对象中）**
- `drawSpeedometerFace(ctx, maxSpeed)` - 绘制表盘底面、边框、装饰环
- `drawTickMarks(ctx, maxSpeed)` - 绘制大小刻度线和数字
- `drawDangerZone(ctx, maxSpeed)` - 绘制红色危险区
- `drawNeedle(ctx, speed, maxSpeed)` - 绘制指针
- `drawCenterCap(ctx)` - 绘制中心帽
- `drawSpeedText(ctx, speed)` - 绘制中心速度数字
- `renderSpeedometer()` - 组合调用以上函数，完整渲染

**C. 修改updateSpeedometer方法**
- 不再操作CSS transform，改为调用`renderSpeedometer()`
- 指针角度计算逻辑保持不变

**D. 修改CSS**
- 移除`.needle`、`.needle-center`、`.tick-mark`、`.tick-label`等CSS类
- 保留`.speedometer`容器样式，调整背景为深色
- 调整`.speed-value`颜色为白色（深色底上显示）

**E. RPM条样式微调**
- 背景改为深色，与仪表盘风格统一
- 保持现有渐变色彩逻辑

### 4. 仪表盘绘制参数

```
角度范围：-135° 到 +135°（270°弧度，与现有逻辑一致）
表盘半径：180px（Canvas 400x400中心）
刻度线起始半径：155px（大刻度），160px（小刻度）
刻度线长度：20px（大刻度），12px（小刻度）
数字半径：130px
指针长度：140px
指针底宽：8px
中心帽半径：15px
危险区阈值：maxSpeed * 0.8
```

### 5. 物理模型优化

现有物理模型基本合理，但做以下微调：
- 加速初期（0-30km/h）增加一个起步延迟因子，模拟离合器接合
- 电动车车型取消起步延迟，模拟电机瞬时扭矩特性
- 在carData中为每款车型增加`isEV`字段标识电动车型

## 假设与决策

1. **Canvas vs SVG**：选择Canvas，因为需要频繁重绘指针位置，Canvas性能更好
2. **DPI适配**：使用2x Canvas确保Retina屏幕清晰
3. **保留现有功能**：所有现有交互逻辑、物理引擎、数据面板保持不变
4. **深色仪表盘+浅色面板**：这是真实汽车的常见设计，也符合"简洁不科幻"的要求
5. **不引入新依赖**：纯Canvas绘制，不引入Chart.js等库

## 验证步骤

1. 选择不同品牌车型，确认仪表盘量程正确更新
2. 按住油门，观察指针平滑转动，速度数字同步更新
3. 松开油门，观察滑行减速和指针回落
4. 按住刹车，观察快速减速
5. 键盘W/S控制正常
6. 重置功能正常
7. 速度曲线图正常绘制
8. 不同屏幕尺寸下仪表盘自适应
9. 电动车与燃油车起步行为差异
